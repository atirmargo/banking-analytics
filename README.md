# 🏦 Анализ клиентов банка: юнит-экономика и сегментация

> Проект по продуктовой аналитике для демонстрации навыков расчёта LTV/CAC, сегментации клиентов, Retention-анализа и A/B-тестирования.

---

## 📌 Описание проекта

**Цель:**  
Проанализировать клиентскую базу банка, чтобы выделить прибыльные и убыточные сегменты, рассчитать юнит-экономику и предложить рекомендации для оптимизации маркетинговых затрат.

**Задачи:**
- Объединить данные о клиентах, счетах и транзакциях.
- Рассчитать ключевые метрики: ARPU, средний чек, LTV, CAC.
- Провести сегментацию клиентов по величине общих трат.
- Оценить Retention по сегментам.
- Симулировать A/B-тест для проверки гипотез.
- Визуализировать результаты в интерактивном дашборде.

---

## 📂 Данные

Использованы синтетические данные банка (файлы не загружены в репозиторий из-за ограничений GitHub):
- `customer_profiles.csv` — профили клиентов  
- `bank_accounts.csv` — счета клиентов  
- `account_transactions.csv` — транзакции по счетам  
- `transaction_codes.csv` — справочник типов транзакций  

**Результирующий файл:** `analysis_results.csv` — содержит агрегированные метрики по каждому клиенту и используется для дашборда.

## 📊 Этапы анализа

1. **Объединение данных** — связывание таблиц через `account_id` и `customer_id`.
2. **Расчёт метрик**:
   - ARPU (средний доход на клиента)
   - Средний чек и частота покупок
   - LTV (прогноз на 3 года: средний чек × 12 × 3)
   - CAC (20% от первого чека)
   - LTV/CAC для каждого клиента
3. **Сегментация** — 4 группы: 🔴 Premium, 🟡 Gold, 🟢 Silver, 🔵 Bronze (по сумме трат).
4. **Retention-анализ** — доля клиентов, совершивших >1 покупку.
5. **A/B-тест (симуляция)** — случайное разделение на группы А и Б, t-test для проверки различий в выручке.
6. **Визуализация** — дашборд в Yandex DataLens с тремя графиками:
   - Распределение клиентов по сегментам
   - LTV/CAC по сегментам (с целевой линией 3)
   - Retention Rate по сегментам
